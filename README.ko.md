# Tennin 프로그래밍 언어

모든걸 인자함수 `():{}` 와 국 (나라) 그리고 함수로 표현하는 언어다. 함수형 언어라고 하기엔 쫌 그렇고 IOP, ROP 라는 개념이 새로 등장하는 언어인데, 개념은 [설계 문서](tennin-spec.ko.md) 에서 확인 가능하다.

- **1형** `"aa"; "bb"` — 값들. 값이 인자로 전달된다. (`("aa"; "bb"):{}` 의 축약)
- **2형** `("아아"; "비비")` — 괄호로 묶은 값들(`;`로 구분). 인자로 전달된다.
- **2-2형** `{내용}` — 인자 없이 내용만 적는 형태. `():{내용}` 에서 빈 인자 `()` 를 지운 축약이다. `else`, `expand` 처럼 받을 인자가 없는 국이 여기 해당한다.
- **3형 (기본형)** `(인자들):{내용}` — `()`=인자들, `{}`=내용. 인자 함수의 기본 형태. 매개변수·반환타입 슬롯은 기본적으로 생략된다(매개변수는 소국으로 주입, 기본적으로 반환 개념 없음).

- **문법** [tennin-spec](tennin-spec.ko.md)

Hello, World!:

```tennin
using tenn;

#main func helloWorld ():(
    Line.addLine("Hello, World");
):();
```
